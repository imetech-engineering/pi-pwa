# IMeTech Pi

De app staat in `pwa/` en wordt via GitHub Actions naar Pages gepubliceerd.

PWA voor status, historie, diensten en onderhoud van de RPi5 (pi.imetech.nl).
Publieke repo voor GitHub Pages: bevat geen data of sleutels. De backend (pi-monitor) draait op de Pi;
de app koppelt via een eenmalige koppellink en bewaart het token alleen lokaal (IndexedDB).
